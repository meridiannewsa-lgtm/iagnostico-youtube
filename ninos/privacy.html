Privacy Policy

Analisis de YouTube Ninos - last updated: September 20, 2026

Analisis de YouTube Ninos is a personal application used by the owner of a children's YouTube channel. It runs locally on the owner's own computer. This policy explains what data it accesses and how that data is used.

Data the application accesses

When the owner signs in with Google, the application requests access to the owner's own YouTube channel through the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API. It reads channel, playlist and video information (titles, descriptions, tags, view counts, watch-time and retention metrics, traffic sources, impressions and click-through rate). These are aggregated statistics about the owner's channel. The application does not collect personal information about the channel's viewers.

The application can change a video's title, description or tags, or the channel description, only when the owner explicitly approves that specific change on their computer.

How the data is used

  • To show the owner a diagnostic of the channel's performance.
  • To prepare suggestions for improving video metadata, which the owner reviews before anything is changed.

Storage and sharing

  • Access tokens and downloaded reports are stored only on the owner's computer.
  • The data is not sold, not used for advertising and not shared with any third party.
  • There is no server operated by the developer that receives or stores this data.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Deleting the application's local files removes all data it stored.
